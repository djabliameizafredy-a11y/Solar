# Solar — Système solaire 3D interactif

Une petite appli web pour que les enfants découvrent le système solaire : le Soleil, les 8 planètes et la Lune, en 3D.

## Ce qu'on peut faire
- Faire tourner la scène dans tous les sens (souris ou doigt)
- Zoomer et dézoomer (molette, pincement ou boutons)
- Toucher une planète pour la suivre et lire sa fiche (taille, distance, température, anecdote…)
- Régler la vitesse, mettre en pause, afficher ou cacher les orbites et les noms

Les tailles et les distances ne sont pas à l'échelle ; les durées de révolution, elles, respectent les vraies proportions.

## Lancer le projet
Aucune installation : ouvre simplement `index.html` dans un navigateur (connexion internet nécessaire pour charger Three.js et les polices).

Pour le mettre en ligne : *Settings → Pages → Deploy from a branch → main / root*.

## Technologies
HTML, CSS, JavaScript et [Three.js](https://threejs.org/) (r128).
